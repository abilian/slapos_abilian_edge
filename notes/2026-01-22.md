## Quick Reference

| Command | Purpose |
|---------|---------|
| `build-component component <name>` | Build single component |
| `build-component software <name>` | Build single software release |
| `build-all components` | Build all components |
| `build-all software` | Build all software releases |

| Env Variable | Purpose |
|--------------|---------|
| `SLAPOS_CACHE=1` | Enable network cache |
| `SLAPOS_SHOW_OUTPUT=1` | Real-time build output |
